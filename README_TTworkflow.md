# How to use
1. Include these files at the root of a repo:   
- AGENTS.md (If the target repo already has this file, they can probably be merged)
- CHECKLIST.md
- LOG.md
- PLAN.md
- RELEASES.md
- TTE_PROMPT.md
- WHAT.md
- WORKFLOW.md


2. Edit TTE_PROMPT.md to make what you want

3. Tell your agent to run WORKFLOW.md

4. Some agents or versions of agents will stop after a step and need prompting to "continue to the end of the cycle"

5. Find all the deliverables in deliverables/
