# Installation Bundle (cycle-01)

Copy these files onto the UNIHIKER K10 as a folder (example name: `TTDB_DUNGEON/`).

Bundle contents:
- `ttdb_dungeon_crawler.py` — main game
- `ttdb_dungeon_db.md` — dedicated populated TTDB/mmpdb database
- `TTDB_README.md` — installation + run instructions

Suggested on-device layout:

```
TTDB_DUNGEON/
  ttdb_dungeon_crawler.py
  ttdb_dungeon_db.md
  TTDB_README.md
```
