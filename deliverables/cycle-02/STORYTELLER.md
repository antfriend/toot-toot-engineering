# STORYTELLER (cycle-02)

## Narrative focus
This cycle is about trustable memory flow. The operator should feel confident that sync is safe, versioned, and understandable, while the dashboard turns invisible gossip into a visible, living system. The story is: strengthen the handshake, then make the network legible.

## Core story arc
1. **Harden the handshake**: define versioning, signing, and compatibility so old nodes can still participate safely.
2. **Make sync observable**: surface sync status, missing records, and retries in human terms.
3. **Watch the mesh breathe**: live nodes, last-seen, and message flow show the network’s pulse.
4. **Prove continuity**: tests and migration notes show that older nodes still converge.

## Tone and style
- Precise and operator-centered.
- Security is practical and explicit: what is checked, what is not, and why.
- Visualization is purposeful: no fluff, only signals that support decision-making.

## Narrative anchors
- **Handshake as trust**: versioning and signatures are the “ID badge” of a record.
- **Sync health as vitals**: last sync, missing count, and retry rate are the heartbeat.
- **Message flow as weather**: patterns reveal outages or a quiet mesh.

## Suggested section framing
- "Sync protocol v2" (versioning + security + compatibility)
- "Migration story" (old nodes, dual mode, safe fallback)
- "Dashboard as instrument panel" (nodes, sync health, flows)
- "Proof" (tests and expected signals)
