# STORYTELLER (cycle-03)

## Narrative focus
This cycle turns a complex, multi-device build into a repeatable field ritual. The operator should feel guided, safe, and in control: one script, one check, one clear next step at a time. The story is a deployment convoy that arrives, unpacks, powers up, and verifies the mesh in sequence.

## Core story arc
1. **Prepare the convoy**: install tools and stage firmware artifacts.
2. **Flash the scouts**: Heltec nodes and T-Deck are provisioned with a consistent channel identity.
3. **Raise the operator**: K10 comes online as the gateway and console.
4. **Light the beacon**: Windows hub starts first and validates sync readiness.
5. **First contact**: bootstrap the network with a simple presence and message flow check.

## Tone and style
- Calm, precise, and operator-first.
- Scripts explain themselves with dry-run and verify modes.
- Every automation step yields an observable signal.

## Narrative anchors
- **Automation kit as checklist**: no hidden steps.
- **Verification as trust**: every script ends with a proof.
- **Fallbacks are normal**: document when GUI or manual steps are required.
